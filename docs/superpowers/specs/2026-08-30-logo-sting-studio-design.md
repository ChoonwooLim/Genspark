# Logo Sting Studio — 설계 문서

작성일: 2026-08-30
상태: P1 설계 확정, 구현 미착수

> 이 문서는 ECOROID 저장소에 임시로 둔다. 별도 저장소를 만드는 시점에 그쪽으로 옮긴다.

## 1. 무엇을 만드는가

브랜드 로고 이미지 한 장에서 **로고 스팅**(로고 엔딩·인트로 영상)을 생성하고,
AI가 남기는 공백을 서버에서 자동으로 마무리해 완성본으로 납품하는 웹 서비스.

최종 목표는 상용 SaaS다. 다만 한 번에 짓지 않는다 — 아래 로드맵 참조.

### 왜 필요한가

2026-08-30 세션에서 Higgsfield Seedance 2.5로 PLAZION·GreenB 로고 스팅 12편을
실제로 만들면서, AI 생성만으로는 납품이 불가능하다는 것이 실측으로 확인됐다.
생성물은 훌륭하지만 매번 같은 공백이 남았고, 그 공백을 사람이 매번 손으로 메꿨다.

이 서비스의 가치는 **생성**이 아니라 **그 공백을 자동으로 메꾸는 것**이다.
생성 자체는 API 호출 한 번이라 누구나 한다.

### 실측된 공백 (P1 요구사항의 근거)

| 공백 | 실측값 |
|---|---|
| 착지 프레임이 원본 로고와 불일치 | `end_image`를 줘도 로고가 미세하게 이동·축소 |
| 오디오 라우드니스 편차 | VFX 계열 −23dB / 자연 계열 −41dB (18dB 차) |
| 프레임레이트 고정 | 요청과 무관하게 항상 24fps |
| 길이 부정확 | 5초 요청 → 5.06초 출력 |
| 로고 소스 오염 | 애니메이션 시퀀스 마지막 프레임에 브랜드 외 색상 39.6% 혼입 |
| 알파 부재 | 출력에 투명 채널 없음 (→ P4로 연기, 3장 참조) |

## 2. 로드맵

| 단계 | 내용 | 선행 이유 |
|---|---|---|
| **P1** | 생성 + 후반작업 코어 (단일 사용자) | 제품의 심장. 이게 안 돌면 나머지는 껍데기 |
| **P2** | 브랜드 워크스페이스 + 인증·멀티테넌시 | 남의 로고를 받으려면 격리가 먼저 |
| **P3** | 구독 결제 + 크레딧 정산 + 사용량 제한 | 원가(크레딧)가 확정돼야 가격을 매김 |
| **P4** | 알파/매트, 편집 프로젝트 내보내기 | 실무 요구가 실제로 나오면 |

**이 문서는 P1만 다룬다.** P2 이후는 각각 별도 스펙을 쓴다.

P1은 사내에서 먼저 쓴다. ECOROID·GreenB·PLAZION 작업을 이걸로 돌려 파이프라인
품질을 잡고, 그 다음 외부에 연다.

## 3. 알파(투명) 출력을 P1에서 뺀 이유

스파이크로 검증했고 **실패했다.** 근거를 남긴다.

검정 배경 FORGE 영상에 루마키를 걸어 매트를 뽑고, 중간 회색 위에 합성해 확인했다.

| 영역 | 휘도 (0–255) |
|---|---|
| 배경 | 3.0 |
| 로고 평균 | 83.4 (중앙값 62.2) |
| **로고 하위 25%** | **44.6** |

로고의 어두운 4분의 1이 휘도 45다. 배경과 충분히 벌어지지 않아 루마키가 **로고
본체를 반투명으로 판정**했다. 합성 결과 로고 색이 죽고 배경이 비쳤으며, 글로우
경계에 검은 프린지가 생겼다(premultiplied alpha). screen 블렌드는 어두운 로고가
아예 사라졌다.

대안도 막혀 있다:

- **크로마키** — 배경을 그린으로 강제하면 화염·글로우에 색이 물들고 스필이 로고에 묻는다
- **더블 패스 매트** — 정석이지만 AI는 같은 프롬프트로 두 번 돌리면 다른 영상이 나온다. 원천 불가

### 대신 "합성 키트"로 납품한다

1. **검정 배경 완성본** — 편집기에서 Add/Screen으로 얹는다. 화염·파티클은 이쪽이 오히려 정답이고, 실무 로고 스팅은 원래 이렇게 나간다
2. **원본 로고 투명 PNG** — 마지막 정지 로고는 어차피 원본으로 교체하므로 알파가 이미 있다. 오버레이가 실제로 필요한 건 이 부분뿐이다
3. **합성 가이드** — 블렌드 모드·인/아웃 타임코드를 텍스트로 동봉

이로써 매트 추출 서브시스템이 통째로 사라지고 P1이 가벼워진다.

### 자연 컨셉과 알파는 애초에 양립하지 않는다

물·새싹·안개 프리셋은 **배경 자체가 연출**이다. 배경을 걷어내면 남는 게 없다.
알파가 의미 있는 것은 검은 공간에 로고만 떠 있는 VFX 계열뿐이다. P4에서 알파를
붙이더라도 프리셋별 옵션이어야 하며, 자연 계열에서는 UI에서 비활성화한다.

## 4. 아키텍처

ECOROID에서 검증된 스택을 그대로 쓴다: FastAPI + React/Vite + PostgreSQL,
Orbitron 배포. 인프라 리스크를 0에 가깝게 만들고 파이프라인 품질에 집중한다.

```
Web (React+Vite) ──> API (FastAPI) ──> Queue ──> Worker
                          │                        │
                          ├──> PostgreSQL          ├─ logo_prep   로고 검증 + 엔드프레임
                          └──> Storage             ├─ generator   Higgsfield 어댑터
                                                   ├─ post        ffmpeg 마무리 체인
                                                   ├─ qa          자동 품질 게이트
                                                   └─ packager    납품 세트 조립
```

### 모듈 경계

5개로 쪼갠 이유는 **각각이 독립적으로 실패하고 독립적으로 재시도되기 때문**이다.
생성은 3~6분이 걸리고 크레딧을 쓰지만, 후반작업은 몇 초에 공짜다. 후반작업 버그
때문에 생성을 다시 돌리면 돈이 샌다.

| 모듈 | 하는 일 | 의존 |
|---|---|---|
| `logo_prep` | 로고 오염도·해상도·알파 검증, 비율별 엔드프레임 생성 | Pillow |
| `generator` | Higgsfield 호출, 폴링, 결과 다운로드 | Higgsfield API |
| `post` | 착지 교체·오디오 정규화·길이/fps 정리·업스케일 | ffmpeg |
| `qa` | 자동 지표 산출, 콘택트 시트 생성 | ffmpeg, Pillow |
| `packager` | 납품 세트 + 합성 가이드 조립 | — |

`generator`만 인터페이스로 분리한다. 나중에 모델이 바뀌어도 나머지 넷은 안 건드린다.
**나머지는 추상화하지 않는다** — 지금 필요 없는 유연성이다.

### 저장소

**별도 저장소로 간다.** ECOROID는 자원순환 플랫폼이고 이것은 영상 도구다.
도메인이 다르고 릴리스 주기도 따로 가야 한다.

## 5. 후반작업 파이프라인

각 단계는 독립 실행·재시도 가능하고, **생성 원본은 절대 덮어쓰지 않는다.**

| # | 단계 | 처리 | 파라미터 |
|---|---|---|---|
| 1 | 착지 프레임 교체 | 마지막 구간을 원본 엔드프레임으로 크로스페이드 | 디졸브 길이 (프리셋별) |
| 2 | 오디오 정규화 | `loudnorm` + 리미터 | 목표 LUFS (프리셋별) |
| 3 | 길이·fps 정규화 | 목표 길이로 트림, fps 선택 | 24 / 30 |

**P1은 길이를 5초로 고정한다.** 가변 길이는 프리셋의 디졸브 길이·오디오 곡선과
얽혀서 조합이 폭발한다. 5초는 로고 스팅의 실무 표준이고, 이번 세션 12편이 모두
5초였다. 다른 길이가 실제로 요구되면 그때 프리셋별로 연다.
| 4 | 4K 업스케일 (옵션) | Topaz 2160p, 생성 job_id 그대로 전달 | — |

### 1단계의 함정

단순 크로스페이드는 AI 로고와 원본 로고의 위치 차 때문에 **점프가 보인다.**
배경이 정적인 컨셉(안개·물)은 티가 안 나지만, 잔불이 움직이는 FORGE는 드러난다.

→ 디졸브 길이를 **프리셋별 파라미터**로 둔다. 정적 배경 0.3초, 동적 배경 0.6초.

### 2단계의 함정

−41dB를 −16 LUFS로 올리면 게인이 25dB라 **노이즈 플로어도 같이 올라온다.**
자연 컨셉은 조용한 것이 정상이다.

→ 프리셋별 목표 라우드니스를 따로 둔다. VFX 계열 −16 LUFS, 자연 계열 −20 LUFS.
게인이 20dB를 넘으면 QA에서 경고를 띄운다.

### 비율 세트는 후반작업이 아니다

리프레임하면 로고가 잘리므로 **비율마다 재생성**이다. `generator`를 N번 도는
것이고 곧 크레딧이 N배다. UI에서 원가로 명시한다.

## 6. 품질 게이트

### 자동 판정 가능

| 지표 | 기준 |
|---|---|
| 착지 프레임 SSIM (교체 후 vs 원본 엔드프레임) | ≥ 0.99 |
| 출력 라우드니스 | 목표 ±1 LUFS |
| 최종 프레임 로고 영역 색상 vs 브랜드 컬러 | ΔE < 5 |
| 로고 소스 오염도 (입력 단계) | 브랜드 외 색조 < 2% |
| 로고 소스 불투명 픽셀 비율 (입력 단계) | ≥ 60% (미만이면 하프톤/디졸브 중) |

### 자동 판정 불가능

중간 구간에서 워드마크가 뭉개졌는지는 알고리즘이 판정할 수 없다. 파편 조립
프리셋은 중간에 글자가 흩어지는 것이 **의도된 연출**이라 붕괴와 구분되지 않는다.

→ **콘택트 시트를 자동 생성해 검수 화면에 띄우고 사람이 승인한다.**
"완전 자동"을 억지로 주장하지 않는 편이 제품 신뢰에 낫다.

## 7. 데이터 모델

```
Brand      로고 원본(투명), 브랜드 컬러, 오염도 스캔 결과
  └ Job    프리셋 + 비율 + 옵션. 사용자가 "만들어줘"를 누른 단위
      └ Render   비율 1개 = Render 1개. 크레딧 과금 단위
          ├ generation_asset   AI 원본 (불변)
          └ Delivery           마무리본. 같은 generation에서 여러 번 생성 가능
```

`Render` 상태 전이:

```
queued → generating → generated → posting → review → approved
                          ↑            │        │
                          └────────────┴────────┘   재마무리는 generated 부터
실패 시: failed (+ 실패 단계명, 에러 원문 보존)
```

**`generated`에서 멈춰 세울 수 있어야 한다.** 생성이 마음에 안 들면 거기서 버리고
재생성하고, 마무리 단계 문제면 `generated`부터 다시 태운다. 이 분리가 없으면
오디오 게인 하나 고치려고 45크레딧을 또 쓴다.

## 8. 에러 처리

실제로 겪은 실패만 다룬다.

| 실패 | 처리 |
|---|---|
| `mode` 누락 시 422 | 스키마 검증으로 제출 전 차단 |
| 생성 3~6분 소요 | 폴링 백오프. 조급한 재제출 금지 (중복 과금) |
| job이 `type: "image"`로 표시 | Seedance 표기 오류. `status`만 신뢰 |
| 로고 소스 오염 | 업로드 시 스캔해 차단 |
| 저해상도 로고 | 800px 미만이면 배치 폭 비율을 자동으로 낮춤 |
| 업스케일 프리플라이트 불가 | 크레딧 사전 확인 없이 진행. UI에 명시 |

**원칙: 크레딧을 쓰는 호출은 자동 재시도하지 않는다.** 실패하면 멈추고 사람에게 묻는다.

## 9. 테스트 전략

- **`logo_prep`·`post`·`qa`는 순수 함수이므로 전부 자동 테스트한다.**
  고정 픽스처(오염된 로고, 저해상도 로고, −41dB 오디오 클립, 24fps 5.06초 클립)를
  넣고 결과를 검증한다. 2026-08-30 세션 산출물이 그대로 픽스처가 된다.
- **`generator`는 목으로 테스트한다.** 실제 생성은 느리고 비싸다. 계약 테스트로
  파라미터 조립만 검증하고, 실호출은 수동 스모크 1회.
- **골든 파일 회귀** — 같은 입력에 대해 마무리본의 프레임 해시·라우드니스가
  변하지 않는지. ffmpeg 필터를 손댈 때의 안전망.

## 10. 프리셋 (P1 초기 세트)

2026-08-30 세션에서 실제로 검증된 것만 넣는다.

| 프리셋 | 배경 | 계열 | 검증 |
|---|---|---|---|
| FORGE | 딥블랙 | VFX | PLAZION·GreenB 16:9/9:16 |
| SHARD | 딥블랙 | VFX | PLAZION 16:9 |
| ARC | 딥바이올렛 | VFX | PLAZION 16:9/9:16 |
| DEW | 오프화이트 | 자연 | GreenB 16:9/9:16 |
| GROWTH | 오프화이트 | 자연 | GreenB 16:9/9:16 |
| MIST | 딥그린 | 자연 | GreenB 16:9 |

프리셋마다 프롬프트 템플릿 + 디졸브 길이 + 목표 LUFS + 알파 지원 여부를 갖는다.

자연 계열 프롬프트에는 **부정 지시를 길게 나열해야 한다.** 모델 기본값이
"화려한 VFX"라 명시적으로 막지 않으면 불꽃이 들어온다.

## 11. P1에서 하지 않는 것 (YAGNI)

- 인증·회원가입·멀티테넌시 → P2
- 결제·크레딧 정산 → P3
- 알파 출력, 편집 프로젝트 내보내기 → P4
- 모델 추상화 계층 (Higgsfield 외 백엔드) → 필요해지면
- 워크플로 DAG 엔진 → 지금 흐름은 분기 없는 직선
- 자체 로고 에디터 → 사용자가 만들어 온 로고를 받는다
