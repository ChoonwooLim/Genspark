### 세부 내용

**서버 사이드 렌더링 (핵심 신기능)**
- Orbitron이 저장소 `Dockerfile`을 쓰도록 `# CUSTOM` 마커 적용 → Debian 이미지로 전환, chromium·ffmpeg 확보.
- `src/render.node.ts`: 헤드리스 Playwright로 프레임 캡처 → ffmpeg 인코딩. 최초 CDP 가상시간 방식은 컴포지터 스레드 애니메이션(transform/opacity)에는 안 먹혀 전 프레임이 동일하게 나오는 버그 발생 → Web Animations API로 프레임마다 직접 `currentTime` 지정하는 방식으로 교체, 실제 진행 확인(1.2s/4.2s 프레임 상이).
- 내장 엔진은 `/render/engine` 전용 무레이아웃 페이지에서 결정론적 `_draw(t)` 훅으로 시킹.
- 출력 포맷: MP4(H.264, 기본) / WebM(VP9+alpha) / MOV(ProRes 4444+alpha) / PNG 시퀀스(개별 프레임 저장, ZIP은 `?as=zip` 요청 시 즉석 생성).
- PNG는 압축 없이 프레임 그대로 볼륨 저장이 기본 정책(요청 사항 반영), ZIP은 선택 사양.
- 투명 캡처 시 페이지 레벨 배경만 제거(html/body/.stage/.canvas), 요소 자체 배경(디자인)은 보존. 프로토타입이 `mix-blend-mode: screen`을 쓰는 경우 검정 배경 의존을 안내 문구로 경고.

**핸드오프 파이프라인 안정화**
- 스펙 파서를 표 형식(PLAZION) + 불릿 형식(GreenB) + 컨셉별 하위 타임라인까지 일반화. 레이어 번호(1,2,3)나 "16:9 (1920×1080)" 같은 프로즈를 시간으로 오인하던 오탐 다수 수정.
- `detectEntrypoints`가 `design_handoff_*/` 접두사를 요구해 접두사 없이 zip 루트에 바로 있는 번들에서 미리보기 0건이 되던 문제 수정 → 접두 있으면 우선, 없으면 있는 그대로 사용.
- 컨셉-파일 매핑 표(`# | 컨셉 | 16:9 파일 | 9:16 파일 | 무드`)를 읽어 "A · Plasma" 같은 정확한 이름 부여.
- `POST /api/handoffs/:id/reparse`로 기존 업로드 번들도 파서·탐지 로직 개선 시 재업로드 없이 갱신 가능.
- 압축 푼 폴더 선택 기능이 리팩터링 중 유실됐던 것을 원 커밋에서 복원.

**작업실 상태 관리**
- 작업 중인 로고·설정·애니메이션 선택을 IndexedDB `session` 스토어에 저장해 페이지 간(작업실↔미리보기) 이동 시 유지.
- 핸드오프 적용 시 로고만이 아니라 **그 번들의 애니메이션 자체**를 작업실 라이브 프리뷰에서 재생하도록 변경 (기존엔 로고만 바뀌고 애니메이션은 항상 내장 엔진으로 재생되던 버그).
- 작업실 재방문 시 작업 상태를 복원(로고·이름·설정·애니메이션) — 기존엔 매번 새 프로젝트처럼 초기화되던 버그.
- IndexedDB 스키마 v1→v2 업그레이드가 다른 탭에 막혀 무한 대기(오류 없음)하던 버그를 `onblocked` + 타임아웃으로 해결, 실패 시 사용자에게 안내.

**디자인 전면 개편**
- 초기 워크벤치 구조는 스타일 없는 와이어프레임 수준이었음 — 소스 탭 2/3개 백색-온-백색으로 증발, 슬라이더/라디오/체크박스 브라우저 기본형, 스테이지 왜소.
- Opus 서브에이전트에 `docs/DESIGN-cohere.md` 기준 재설계 위임: 다크 스테이지 스타일을 `.stage` 범위로 격리(로드 순서 의존 제거), 전 폼 컨트롤 커스텀 드로잉, 스톤 레일 + 지배적 스테이지 구성.
- 이어서 전 페이지(홈/미리보기/라이브러리/핸드오프/보관함) 통일 + 상단 메뉴바 다크모드(사용자 요청) + 제품명 "Logo Studio"로 변경.
- 홈 히어로 카피를 엔진 스펙 설명("보크셀 3초")에서 "로고가 애니메이션으로 재탄생" 메시지로 재작성, 타이포 80%로 축소, 리드 2문장·17px로 경량화.
- CSS/마크업 변경 시마다 `ASSET_VERSION` 값을 올려 Cloudflare Browser Cache TTL(4시간)을 우회.
